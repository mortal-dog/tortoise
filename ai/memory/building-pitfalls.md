- **Agent worktrees:** a subagent with `isolation: worktree` works in `.claude/worktrees/<name>/`, inside the repo.
  Biome then found a second `biome.json` and refused to run, and the guards' `git ls-files --others` would have read
  the copy. `.claude/` is in `.gitignore` since `491994c`. The worktree started at an old commit and the agent
  fast-forwarded it; merge its branch by `git cherry-pick`.
- **Parallel agents (Phases 5 and 7):** two worktree agents ran e2e at once, so `playwright.config.ts` takes
  `TORTOISE_E2E_PORT` and never reuses a running server (it could be another worktree's build). The docs guard wants
  D-numbers with no gap: give each agent a number, and renumber its entry after main's when cherry-picking (an agent may
  add a placeholder row for a number it does not own). `src/routeTree.gen.ts` always conflicts: take either side and
  run `pnpm exec vite build`, which regenerates it. Remove merged worktrees with `git worktree remove` and
  `git branch -D` (cherry-picked shas differ, so `-d` refuses).
- **TypeScript 7:** the DOM and WebWorker libs conflict in one program, so the service worker has its own
  `tsconfig.sw.json`, and `pnpm check` runs `tsc` twice.
- **The service worker build:** a second Vite (Rolldown) input `src/sw/sw.ts` emitted as `sw.js`; the plugin replaces
  `__PRECACHE__` and `__VERSION__` in `generateBundle` and throws if they are missing. The worker imports nothing, so
  no shared chunk can appear.
- **Playwright:**
  - day travel: `page.clock.setFixedTime(new Date('…T09:00:00Z'))`, then `page.reload()`; IndexedDB survives.
  - `getByRole(name)` matches a substring: two links "Week" and "Back to the week" collide; use `exact: true`.
  - `locator.check()` failed on a checkbox whose state comes back from IndexedDB after the write; the control now shows
    the tap at once (local state, synced from the stored value).
  - `fullPage` screenshots draw the fixed tab bar in the middle of the page; it is an artefact, not a layout bug.
  - offline is proven by a fetch of an uncached URL that must fail; `context.setOffline` alone proves nothing.
  - timers: `setFixedTime` freezes `Date.now`, so the player and stopwatches need `page.clock.install({ time })`, then
    `runFor` (fires every timer) or `fastForward` (jumps, firing due timers once: it stands in for the background).
    Change the date with `setSystemTime` and reload, or `goto('/')` when the current page is not Today.
  - `locator.isVisible()` throws in strict mode when the name matches two elements (two "Right" buttons), so a
    `.catch(() => false)` helper silently loops: use `.first().isVisible()`.
  - a flaky e2e under load found a real race: "Finish" read the test record before a card's save had landed. Run a
    failing spec alone before blaming the test.
  - another one, 2026-11-22: the reminders test typed the morning time, then Monday's, and lost the morning time.
    `saveSettings` read and wrote in two transactions, and the fields spread the rendered copy (`{ ...r, field }`), so
    the second save wrote back the copy from before the first. Since `7f2ef15` the read and the write share one
    transaction and nested fields are saved as a function of the stored record; `tests/db/settings.test.ts` starts two
    saves at once. A flaky test that loses an earlier input is a lost update until shown otherwise.
  - a slow or flaky e2e only on CI can be rendering: CI's WebKit has no GPU, so the e2e render at 1x there
    (`TORTOISE_E2E_DPR`, D-049); the numbers are in [[ci-pipeline]].
- **Vitest:** `process.env.TZ = 'Europe/London'` at the top of `vitest.config.ts` gives every worker a zone with
  daylight saving; `-0` from `-getTimezoneOffset()` fails `toBe(0)`.
- **NOAA reference values:** running NOAA's calculator script (`gml.noaa.gov/grad/solcalc/main.js`), even in a node
  `vm`, was refused by the auto-mode classifier. The values were read as data from NOAA's published
  `NOAA_Solar_Calculations_year.xls` (`uv run --no-project --with xlrd python -I`, columns 23–26: solar noon, sunrise,
  sunset in day fractions, day length in minutes; its own example 40° N, 105° W, zone −7, year 2010). The sheet makes
  one pass at noon, so the test tolerance is 1 minute.
- **New routes** do not type-check until the route tree is regenerated: run `pnpm exec vite build` once after adding a
  file in `src/routes/`.
- **Biome:** comma expressions in arrow bodies (`() => (a(), b())`) fail `noCommaOperator`; a JSX element assigned to a
  `const` inside `.map()` needs its own `key`; `<svg role="img">` needs a `<title>`.
- **A deploy run from the session:** `gh workflow run ci.yml` (it deploys) was refused by the auto-mode classifier even
  after the owner approved Pages. It went through once the owner's picker in the same session named it ("Push and
  deploy now", 2026-11-22). A run with `-f deploy=false`, or on a branch, deploys nothing and ran without asking.
- **Bugs the Phase 2 tests caught:** with one log, `slice(-2)` put it in `prev`, not `latest` (use `at(-1)`/`at(-2)`).

**Why:** each cost a failed gate or a refused step on 2026-11-22 (Phases 0–9, then the settings race and the CI
work).

**How to apply:** check these first when a gate fails in the same place ([[guard-tests]]).
